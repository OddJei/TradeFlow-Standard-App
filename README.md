# Standard TradeFlow App

## Repository purpose

This repository is the public evidence and showcase copy of the reusable
Standard TradeFlow Apps Script application. It was created to show the
reference business-system implementation, tests and integration contracts
that support portfolio review and future compatible business editions.

Parent platform: [NTheemba Platform](https://github.com/OddJei/NTheemba-Platform)

TradeFlow remains the authoritative business system for tenant-owned
operational facts such as price, stock, availability and local policy. This
repository is the standard/reference edition, not a client-specific copy.

Active Apps Script edition:
`appscript/`

This is the standard/reference TradeFlow edition. Use it as the baseline for reusable workflows and compatibility checks before adapting changes into customised editions.

The standard app should stay free of client-specific secrets, spreadsheet IDs, deployment IDs, private contact details, and business-only overrides.
