## 1. EXECUTIVE SUMMARY

### 1.1 Overview
TradeFlow Pro is a comprehensive, offline-first inventory management system built on Google Apps Script with a mobile-first HTML/CSS/JS frontend. It serves as a complete business operations platform for retail and wholesale businesses across Zambia, integrating:

- **Sales Management** with cart-based checkout
- **Barcode Scanning** - HID scanner (primary) + Camera (secondary) + Manual entry
- **Voice Input** - Speech-to-text for hands-free product search
- **Inventory Control** with FIFO batch cost tracking
- **Procurement System** with budget builder and purchase orders
- **Stock Adjustments** for damage, theft, returns, and corrections
- **Staff Management** with role-based access
- **Financial Reporting** with daily/weekly/monthly ledgers
- **Admin Dashboard** with real-time analytics
- **Multi-Business Support** with 15+ business types and category sets

### 1.2 Core Value Proposition
- **Never Run Out of Stock** - Automatic reorder suggestions based on Min/Max stock
- **Accurate Cost of Goods Sold (COGS)** - FIFO batch cost tracking
- **Optimized Cash Flow** - Buy only what you need with budget builder
- **Complete Audit Trail** - Every transaction recorded and traceable
- **Mobile-First Design** - Works on phones, tablets, and desktop
- **Offline Capable** - Works without internet using IndexedDB
- **Barcode Ready** - HID scanners + Camera + Manual entry
- **Voice Enabled** - Hands-free product search
- **Multi-Business Ready** - 15+ business types with pre-configured categories

## 2. SYSTEM ARCHITECTURE

### 2.1 Technology Stack

| Layer | Technology | Purpose |
|-------|-----------|---------|
| **Frontend** | HTML5, CSS3, JavaScript (ES6) | User interface, responsive design |
| **Backend** | Google Apps Script (ES5) | Business logic, sheet operations |
| **Database** | Google Sheets | Primary data storage |
| **Cache** | CacheService (server), sessionStorage (client) | Performance optimization |
| **Offline** | IndexedDB (client), Cache API | Offline operations |
| **Hosting** | Google Apps Script Web App | Deployment |
| **Barcode** | HID Keyboard Emulation (primary), Camera (secondary) | Scanner input |
| **Voice** | Web Speech API | Speech-to-text for hands-free search |

### 4.2 Algorithms

#### 4.2.1 Barcode Processing (O(1))
```javascript
function processBarcode(barcode) {
  // 1. Normalize barcode (strip spaces, validate)
  barcode = normalizeBarcode(barcode);
  
  // 2. Check minimum length
  if (barcode.length < 3) return null;
  
  // 3. Check barcode cache (sessionStorage)
  var cached = getBarcodeCache(barcode);
  if (cached) return cached;
  
  // 4. Look up in BarcodeLookup sheet
  var product = lookupBarcodeInSheet(barcode);
  
  // 5. If not found, search ProductMaster by barcode column
  if (!product) {
    product = searchProductByBarcode(barcode);
  }
  
  // 6. Cache result for future scans
  if (product) {
    updateBarcodeCache(barcode, product);
  }
  
  // 7. Log scan history
  logBarcodeScan(barcode, product, getCurrentContext());
  
  //    Total: O(1) with cache, O(n) on cache miss
  return product;
}
```

#### 4.2.2 Voice Search (O(n))
```javascript
function voiceSearch(query) {
  // 1. Normalize query (lowercase, remove extra spaces)
  query = normalizeQuery(query);
  
  // 2. Get all products from ProductMaster
  var products = getAllProducts();
  
  // 3. Calculate match score for each product
  var results = products.map(function(product) {
    var score = 0;
    var name = product.productName.toLowerCase();
    var words = query.split(' ');
    
    // 3a. Exact match bonus
    if (name === query) score += 100;
    
    // 3b. Starts with bonus
    if (name.startsWith(query)) score += 50;
    
    // 3c. Word match
    words.forEach(function(word) {
      if (name.includes(word)) score += 10;
      if (name.split(' ').indexOf(word) > -1) score += 20;
    });
    
    // 3d. Partial match
    if (query.length > 3 && name.includes(query)) score += 30;
    
    return {
      productId: product.productId,
      productName: product.productName,
      score: score,
      stock: product.currentStock
    };
  });
  
  // 4. Sort by score (highest first)
  results.sort(function(a, b) { return b.score - a.score; });
  
  // 5. Return top matches
  //    Total: O(n log n)
  return results.slice(0, 10);
}
```

```javascript
function buildStockMap() {
  // 1. Sum all restock quantities by product ID
  //    Time: O(R) where R = restock log rows
  // 2. Subtract all sales quantities by product ID
  //    Time: O(S) where S = sales log rows
  // 3. Cache result with 90 second TTL
  //    Total: O(R + S)
  return stockMap;
}
```

```javascript
function allocateFifoCosts(productId, qty) {
  // 1. Get all active batches for product
  //    Time: O(B) where B = batch count
  // 2. Sort by purchase date (oldest first)
  //    Time: O(B log B)
  // 3. Deduct from oldest batches until qty fulfilled
  //    Time: O(B)
  //    Total: O(B log B)
  return allocation;
}
```

```javascript
function buildBudget() {

  return budgetItems;
```

```javascript
function generateProductId(sheet) {
```

#### 6.2.2 Focus Management
```javascript
function initHIDScanner() {
    var input = document.getElementById('barcodeInput');
    
    // 1. Auto-focus on page load
    input.focus();
    
    // 2. Refocus after any click outside input fields
    document.addEventListener('click', function(e) {
        var tag = e.target.tagName.toLowerCase();
        var isInput = tag === 'input' || tag === 'select' || tag === 'textarea';
        if (!isInput) {
            input.focus();
        }
    });
    
    // 3. Refocus after tab changes
    document.addEventListener('visibilitychange', function() {
        if (document.visibilityState === 'visible') {
            input.focus();
        }
    });
    
    // 4. Input event - process barcode
    input.addEventListener('input', function(e) {
        var value = this.value;
        if (value.length > 0) {
            // Process after short delay (ensures complete scan)
            setTimeout(function() {
                processBarcode(value);
                input.value = '';
            }, 50);
        }
    });
    
    // 5. Enter key fallback
    input.addEventListener('keydown', function(e) {
        if (e.key === 'Enter') {
            var value = this.value;
            if (value.length > 0) {
                processBarcode(value);
                this.value = '';
            }
        }
    });
}
```

```javascript
function initCameraScanner() {
    var cameraBtn = document.getElementById('cameraBtn');
    var videoContainer = document.getElementById('videoContainer');
    var video = document.getElementById('videoElement');
    var canvas = document.getElementById('canvasElement');
    var scanResult = document.getElementById('scanResult');
    
    cameraBtn.addEventListener('click', function() {
        // Show camera overlay
        videoContainer.style.display = 'block';
        scanResult.textContent = 'Position barcode in frame...';
        
        // Start camera
        if (navigator.mediaDevices && navigator.mediaDevices.getUserMedia) {
            navigator.mediaDevices.getUserMedia({ 
                video: { 
                    facingMode: 'environment',
                    width: { ideal: 640 },
                    height: { ideal: 480 }
                } 
            })
            .then(function(stream) {
                video.srcObject = stream;
                video.play();
                startBarcodeScanning();
            })
            .catch(function(err) {
                scanResult.textContent = 'Camera access denied. Using manual entry.';
                closeCamera();
            });
        } else {
            scanResult.textContent = 'Camera not supported on this device.';
            closeCamera();
        }
    });
}

function startBarcodeScanning() {
    var video = document.getElementById('videoElement');
    var canvas = document.getElementById('canvasElement');
    var context = canvas.getContext('2d');
    
    // Scan every 200ms
    var scanInterval = setInterval(function() {
        // Capture frame
        context.drawImage(video, 0, 0, canvas.width, canvas.height);
        var imageData = context.getImageData(0, 0, canvas.width, canvas.height);
        
        // Use QuaggaJS or ZXing to decode barcode
        // Simplified - in production use a library
        var result = decodeBarcode(imageData);
        if (result) {
            clearInterval(scanInterval);
            closeCamera();
            processBarcode(result);
        }
    }, 200);
    
    // Store interval for cleanup
    window._scanInterval = scanInterval;
}

function closeCamera() {
    var video = document.getElementById('videoElement');
    var stream = video.srcObject;
    if (stream) {
        var tracks = stream.getTracks();
        tracks.forEach(function(track) { track.stop(); });
        video.srcObject = null;
    }
    document.getElementById('videoContainer').style.display = 'none';
    if (window._scanInterval) {
        clearInterval(window._scanInterval);
        window._scanInterval = null;
    }
}
```

```javascript
function initManualEntry() {
    var input = document.getElementById('searchInput');
    var debounceTimer;
    
    input.addEventListener('input', function(e) {
        var value = this.value.trim();
        
        // Clear previous timer
        clearTimeout(debounceTimer);
        
        if (value.length === 0) {
            clearResults();
            return;
        }
        
        // Debounce search
        debounceTimer = setTimeout(function() {
            // Check if it looks like a barcode (numeric or alphanumeric)
            if (isBarcodeFormat(value)) {
                processBarcode(value);
                input.value = '';
            } else {
                // Regular search
                performSearch(value);
            }
        }, 300);
    });
}
```

### 6.5 Context-Dependent Actions

The same barcode input does different things based on the active screen:

```javascript
function processBarcode(barcode) {
    var context = getCurrentContext();
    var product = lookupProduct(barcode);
    
    if (!product) {
        showToast('Product not found: ' + barcode);
        return;
    }
    
    switch(context) {
        case 'sales':
            // Add to cart
            addToCart(product);
            playFeedback('beep');
            showToast('Added: ' + product.productName);
            break;
            
        case 'restock':
            // Pre-fill restock form
            prefillRestockForm(product);
            playFeedback('beep');
            break;
            
        case 'search':
            // Show product details
            showProductDetails(product);
            playFeedback('beep');
            break;
            
        case 'adjustment':
            // Pre-fill adjustment form
            prefillAdjustmentForm(product);
            playFeedback('beep');
            break;
            
        case 'budget':
            // Add to budget list
            addToBudget(product);
            playFeedback('beep');
            showToast('Added to budget: ' + product.productName);
            break;
            
        case 'receive':
            // Mark item as received
            markItemReceived(product);
            playFeedback('beep');
            break;
            
        default:
            // Show product details
            showProductDetails(product);
    }
}

function getCurrentContext() {
    // Check which panel/tab is active
    var activePanel = document.querySelector('.panel.active');
    if (!activePanel) return 'search';
    
    var id = activePanel.id;
    if (id === 'salesPanel') return 'sales';
    if (id === 'restockPanel') return 'restock';
    if (id === 'staffIssuesPanel') return 'search';
    if (id === 'budgetPanel') return 'budget';
    if (id === 'adjustmentsPanel') return 'adjustment';
    if (id === 'receivePanel') return 'receive';
    
    return 'search';
}
```

### 7.2 Password Storage

#### 7.2.1 Hashing Algorithm
```javascript
function hashPortalPassword(portal, username, password) {
  // 1. Create material: portal:username:password
  const material = portal + ":" + username.toLowerCase() + ":" + password;
  
  // 2. SHA-256 hash
  const digest = Utilities.computeDigest(
    Utilities.DigestAlgorithm.SHA_256,
    material,
    Utilities.Charset.UTF_8
  );
  
  // 3. Convert to hex string
  return "sha256:" + bytesToHex(digest);
}
```

#### 14.1.2 Voice Recognition
```javascript
function initVoiceSearch() {
    var voiceBtn = document.getElementById('voiceBtn');
    var searchInput = document.getElementById('searchInput');
    var isListening = false;
    var recognition = null;
    
    // Check browser support
    if (!('webkitSpeechRecognition' in window) && !('SpeechRecognition' in window)) {
        voiceBtn.style.display = 'none';
        return;
    }
    
    // Create recognition instance
    var SpeechRecognition = window.SpeechRecognition || window.webkitSpeechRecognition;
    recognition = new SpeechRecognition();
    recognition.lang = 'en-ZM';
    recognition.continuous = false;
    recognition.interimResults = true;
    recognition.maxAlternatives = 3;
    
    recognition.onresult = function(event) {
        var results = event.results;
        var transcript = '';
        var confidence = 0;
        
        for (var i = 0; i < results.length; i++) {
            if (results[i].isFinal) {
                transcript = results[i][0].transcript;
                confidence = results[i][0].confidence;
                break;
            }
        }
        
        if (transcript) {
            searchInput.value = transcript;
            performVoiceSearch(transcript);
            stopListening();
        }
    };
    
    recognition.onerror = function(event) {
        console.log('Voice recognition error:', event.error);
        stopListening();
        
        if (event.error === 'not-allowed') {
            showToast('Microphone access denied');
        } else if (event.error === 'no-speech') {
            showToast('No speech detected, try again');
        }
    };
    
    recognition.onend = function() {
        stopListening();
    };
    
    function startListening() {
        if (isListening) return;
        isListening = true;
        voiceBtn.classList.add('listening');
        voiceBtn.querySelector('.voice-status').textContent = 'Listening...';
        searchInput.placeholder = '🎤 Listening...';
        recognition.start();
    }
    
    function stopListening() {
        if (!isListening) return;
        isListening = false;
        voiceBtn.classList.remove('listening');
        voiceBtn.querySelector('.voice-status').textContent = 'Say product';
        searchInput.placeholder = 'Search products or type barcode...';
        try { recognition.stop(); } catch(e) {}
    }
    
    voiceBtn.addEventListener('click', function(e) {
        e.preventDefault();
        if (isListening) {
            stopListening();
        } else {
            startListening();
        }
    });
    
    // Stop listening if user types
    searchInput.addEventListener('focus', function() {
        if (isListening) stopListening();
    });
}

function performVoiceSearch(query) {
    var context = getCurrentContext();
    
    // Show loading state
    showToast('Searching: "' + query + '"');
    
    runServer('voiceSearch', {
        query: query,
        context: context
    }, function(results) {
        if (!results || !results.length) {
            showToast('No products found for "' + query + '"');
            return;
        }
        
        // Display results
        displayVoiceResults(results);
        
        // Log voice query
        logVoiceQuery(query, results[0], context);
    });
}
```

### 14.2 Voice Training & Optimization

```javascript
function optimizeVoiceSearch() {
    // 1. Build product name index
    var products = getAllProducts();
    var nameIndex = {};
    var wordsIndex = {};
    
    products.forEach(function(product) {
        var name = product.productName.toLowerCase();
        var words = name.split(' ');
        nameIndex[name] = product;
        
        words.forEach(function(word) {
            if (!wordsIndex[word]) wordsIndex[word] = [];
            wordsIndex[word].push(product);
        });
    });
    
    // 2. Cache for quick lookups
    sessionStorage.setItem('voiceNameIndex', JSON.stringify(nameIndex));
    sessionStorage.setItem('voiceWordsIndex', JSON.stringify(wordsIndex));
    
    // 3. Pre-load common phrases
    var commonPhrases = [
        'i want', 'need', 'looking for', 'can i get',
        'do you have', 'price of', 'cost of', 'how much'
    ];
    sessionStorage.setItem('voiceCommonPhrases', JSON.stringify(commonPhrases));
}

function smartVoiceSearch(query) {
    // 1. Clean query
    query = query.toLowerCase().trim();
    
    // 2. Remove common phrases
    var commonPhrases = JSON.parse(sessionStorage.getItem('voiceCommonPhrases') || '[]');
    commonPhrases.forEach(function(phrase) {
        query = query.replace(phrase, '');
    });
    
    query = query.trim();
    
    // 3. Check exact match
    var nameIndex = JSON.parse(sessionStorage.getItem('voiceNameIndex') || '{}');
    if (nameIndex[query]) {
        return [nameIndex[query]];
    }
    
    // 4. Check word index
    var wordsIndex = JSON.parse(sessionStorage.getItem('voiceWordsIndex') || '{}');
    var words = query.split(' ');
    var matches = {};
    
    words.forEach(function(word) {
        if (wordsIndex[word]) {
            wordsIndex[word].forEach(function(product) {
                var id = product.productId;
                if (!matches[id]) {
                    matches[id] = { product: product, score: 0 };
                }
                matches[id].score += 10;
            });
        }
    });
    
    // 5. Score and sort
    var results = Object.values(matches);
    results.sort(function(a, b) { return b.score - a.score; });
    
    return results.map(function(match) { return match.product; });
}
```
